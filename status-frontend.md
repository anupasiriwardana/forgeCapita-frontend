## 1. Executive Summary

`forgecapita-frontend` is a Next.js 16 / React 19 app on Wagmi + Viem + RainbowKit, multi-chain (Arbitrum Sepolia 421614, BSC Testnet 97) against the deployed v2 contracts. It is wallet-first (nonce + signature sign-in, httpOnly cookie session, role badge) and covers the main journeys for investors, founders and staff/admin: marketplace with filters; project detail with funding, gasless claim and stake, voting, milestones, creator funds, guardian controls, transparency, gas ledger and takeover voting; P2P market; portfolio; founder application and launch pipeline; profile gate; and a multi-tab staff/admin console.

What is NOT built: the design system and app shell (FE-01 to FE-07: the UI still uses the original indigo glassmorphism styling, no component library, no `/design` page, no error/404 pages, no security headers), chain switcher and toasts (FE-11, FE-14), gas tracker and busy-network handling (FE-41, FE-42, FE-44), file uploads (FE-52), notification centre (FE-74), the full founder application stepper (FE-50 remainder, FE-51), and all quality work (no unit or e2e tests, no responsive/Lighthouse audit; CI runs lint, tsc and build only). The user dropped the email/password account pages (FE-20..23); FE-135..137, FE-140 and FE-143 are deferred; FE-146 is a low-priority cleanup.

Stack (package.json, 2026-11-16): next 16.4.2, react / react-dom 19.3.0, wagmi ^2.19.5, viem ^2.57.10, @rainbow-me/rainbowkit ^2.2.11, @tanstack/react-query ^5.104.5, tailwindcss ^4, typescript ^5, eslint ^9. tsconfig target is still ES2017 (FE-10b: no bigint literals, use `BigInt(n)`). Scripts: dev, build, start, lint, abis.

## 2. Operational Features (code present; runtime verification per backlog)

Routes under `app/`: `/` (landing), `/projects` (marketplace with URL-driven filters), `/how-it-works`, `/about`, `/legal`, `/projects/[id]`, `/projects/[id]/milestones`, `/projects/create` (gated launch form with minimum goal, repo picker, launch drafts), `/portfolio`, `/p2p`, `/launches`, `/apply`, `/founder`, `/profile`, `/admin`. There are no `/investor`, `/staff` or `/design` routes: the investor view is `/portfolio`, staff and admin share `/admin`.

- **Auth:** `components/web3/AuthProvider.tsx` (wallet sign-in, session, loading while wagmi reconnects), `ProfileGate` + `useWriteAllowed` (incomplete profile redirects to `/profile`; action disables in InvestorPanel, Fund/Stake, ComplaintDialog), role-aware shell (components/shell/AppShell, AppSidebar, PublicTopBar; replaced the old Navbar in WS-18.1) with session controls.
- **Landing (`/`):** hero, how-it-works cards, 3 featured projects, FAQ (`#faq`); static pages `/how-it-works`, `/about`, `/legal` (draft banner).
- **Marketplace (`/projects`):** `ProjectCard` with chain badge and funding phase, `MarketplaceFilters` (chain, status, category, search, sort, paging).
- **Project detail (`/projects/[id]`):** responsive two-column layout; panels: ProfileEditor, DeveloperPanel (close funding), CreatorFunds, GuardianPanel, FundingGate / fund card, InvestorPanel (user-paid stake, unstake, claim yield, refunds; gasless claim tokens and stake via Permit with pay-gas fallback), MilestonePanel (start vote, execute, finalise), TransparencyPanel, GasLedger, TakeoverPanel, ReportProblem / ComplaintDialog; IndexerLagNote where indexer data is shown.
- **Milestones page:** on-chain reads, gasless EIP-712 vote with wallet chain guard, quorum / fast-track bars.
- **P2P (`/p2p`):** listings and recent trades from the indexer, approve then create, cancel, fill, 1% fee display, token picker, optimistic updates.
- **Portfolio (`/portfolio`):** indexer positions, claimable yield, vote-open and refund badges, gasless request history, my complaints.
- **Founder side:** `/apply` (application with KYC link), `/founder` (4 eligibility checks, agreement signing, shadow wallet pool, repo provisioning and repo list, candidate takeover accept), `/launches` (my launch drafts).
- **Staff/admin (`/admin`, `components/admin/*`):** tabs Applications, Shadow wallets, Users (admin only), Audit log, Launch drafts (read-only), Relay (with relayer status strip), Compliance (resolve / shutdown), Complaints, Takeover (prepare, open, close, execution, repo handover).
